criar projeto React utilizando o VITE

$ npm create vite meuApp01
	ou
$ npm create vite@latest meuApp01	

	-	Selecione o React
	-	Selecione o Javascript

	- Entra no diretório da aplica~ção
		cd meuApp01
	- Instalar os pacotes do node
		npm install
	- Executar a aplicação que por padrão esta no script [dev].
		npm run dev
	- Atualizar o NPM "se necessário" 
		npm install -g npm
	- Instala o gerenciador de rotas do React
		npm install react-router-dom
	- Instal o gerenciador de rotas formulariosReact
		npm i react-hook-form

	

	Instale o [ ES7+ React/Redux/React-Native snippets ]  +14mi Users para os snippets.
	- o snippet [ rafc  ] cria a estrutura básica para um novo componente.
	- o snippet [ rafce ] cria a estrutura básica para um novo componente com export.
	- o snippet [ rafcp ] cria a estrutura básica para um novo componente com export e propTypes.
