# Desenvolvimento das Telas de Login e Cadastro
React + TypeScript + Vite

Em dupla, vocês devem criar as telas utilizando HTML, CSS e JavaScript para simular um sistema de
autenticação.
Requisitos para a Tela de Cadastro:
- Deve conter os seguintes campos:
    o Nome
    o E-mail
    o Senha
    o Confirmação de Senha
    o Botão Cadastrar
    - Mensagens de erro para entradas inválidas, como:
      o E-mail em formato inválido
      o Senhas que não coincidem
      o Senha fraca (menos de 8 caracteres)
      o Campos vazios
- Requisitos para a Tela de Login:
  o Deve conter os seguintes campos:
      o E-mail
      o Senha
      o Botão Entrar
  o Mensagens de erro para entradas inválidas, como:
      o Usuário não encontrado
      o Senha incorreta
      o Campos vazios
o Mensagem de sucesso caso o login seja realizado corretamente.
